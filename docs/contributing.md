# Contributing

Start with a reproducible problem or a suggestion. Use synthetic examples and do not post private notes, personal data or credentials.

Outside code, templates and substantial authored text are not accepted for inclusion until RandomState42 Labs LLC has a separate contributor agreement and the contributor has completed it. Opening an issue, forking the project or accepting the user license is not an assignment of your work to RS42. Report a bug or explain a proposed correction without sending a patch until that process is available.

## Review expectations

- Keep source, setup, starter content and documentation consistent.
- Preserve users' notes, settings and human-owned instruction files.
- Make missing prerequisites and partial setup failures visible.
- Test a fresh workspace and a customized existing workspace for setup changes.
- Keep personal data, private operational material and machine-specific paths out of public contributions.
- Leave the final production merge to a human maintainer.
