# Future first-use recording

No product walkthrough videos have been recorded. This is an outline for a later recording, not an existing demo.

## A useful short walkthrough

1. State the benefit: organize knowledge and put it to work with AI, using context in files the person owns.
2. Show the selected release and an empty synthetic workspace destination, separate from the product checkout.
3. Install workspace files and skills for one supported assistant. Show authentication separately without exposing account details.
4. Open a fresh assistant session and verify it loads the selected Lite package.
5. Invoke `setup-context`. Choose a fictional outcome and show the option to skip.
6. Work through an area, goal, project and task. Show the actual note preview and any instruction decision before approving writes.
7. Inspect the saved files, their links and the next action. Resume from that context in another session.
8. Optionally open the same files in Obsidian, explaining that it adds an interface and dashboard views.
9. Point to setup, update guidance and the public community destination.

Use only synthetic notes and test accounts. Show actual behavior and pauses; do not hide unresolved instruction or installation failures. Record the release, operating system and assistant version. A simulated skill conversation is not footage of a clean client installation.

Later examples can show a Morning Brief, an existing-vault update, project status refresh and workflow approval. Record Windows separately after testing on a real Windows environment. A recording is useful evidence once it exists, but is not required to review the package.
