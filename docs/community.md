# Community and support

AI-OS Lite is built by [RS42](https://rs42.ai/). The current website destination is RS42; a dedicated AI-OS product website will come later.

## Public Discord entry

[Join the RS42 Discord](https://discord.gg/9axRtknSY) and begin in `#📌-start-here`. Use `#ai-os-help` for setup questions and feedback, `#general` for conversation, and `#ai-news` for updates and discussion. AI-OS Lite uses the existing RS42 community.

Keep shared examples small and remove credentials, personal information and private work before posting.

## Questions and bug reports

Use [GitHub Issues](https://github.com/RS42-AI/ai-os-lite/issues) for reproducible bugs, documentation problems and feature requests. Include:

- Your operating system and whether you use WSL.
- Your assistant and version.
- The AI-OS Lite release or commit you tested.
- The smallest reproduction and redacted output.
- What you expected and what happened.

For setup questions, use `#ai-os-help` in Discord. You can also find RS42 at [rs42.ai](https://rs42.ai/). No support response time, service-level agreement or paid package is established by this repository.

## Security-sensitive reports

Do not disclose secrets or private information in a public issue. If GitHub shows a private vulnerability-reporting option in this repository's Security tab, use it. Otherwise contact RS42 through its website to arrange a private reporting route before sharing sensitive details. Private reporting availability has not been verified by this candidate.
